dedicated key:

ssh-keygen -t ed25519 -C "backdoorsecurity@proton.me" -f ~/.ssh/id_ed25519_github
cat ~/.ssh/id_ed25519_github.pub

point GitHub at key:

cat >> ~/.ssh/config <<'EOF'

Host github.com
  HostName github.com
  User git
  IdentityFile ~/.ssh/id_ed25519_github
  IdentitiesOnly yes
EOF
chmod 600 ~/.ssh/config

2. Add the public key on GitHub

GitHub → Settings → SSH and GPG keys → New SSH key. Paste the .pub line.

Then:

ssh-keyscan -t ed25519 github.com >> ~/.ssh/known_hosts
ssh -T git@github.com

You want: Hi <user>! You've successfully authenticated...

git config --global user.name "backdoorsecurity"

cd "project"
